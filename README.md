# Midad Smart Traffic Project

نظام ذكي لعدّ وتصنيف المركبات على طريق مدفوع باستخدام Computer Vision.

## نظرة عامة

يهدف المشروع إلى تطوير نظام ذكي يُثبّت على كاميرا مراقبة فوق طريق مدفوع (Toll Road) ذي اتجاهين، بحيث يقوم النظام بـ:

- كشف المركبات وتصنيفها (سيارة، فان، باص، شاحنة، موتور)
- عدّ المركبات المارة مع منع الازدواج
- حساب رسوم العبور حسب نوع المركبة
- مراقبة السرعة والإبلاغ عن المخالفات
- إصدار تقارير نهائية بالإيرادات

## التقنيات المستخدمة

- Python 3.10+
- YOLO11n (Ultralytics) - لكشف المركبات
- OpenCV - لمعالجة الفيديو
- IoU/Centroid Tracking - لتتبع المركبات
- NumPy, Matplotlib - للمعالجة والرسم

## اختيار العتبة (Confidence Threshold)

جربنا 4 قيم:

| القيمة | عدد المركبات | ملاحظات |
|--------|--------------|---------|
| 0.5 | 6 | تفوت مركبات بعيدة |
| 0.4 | 8 | جيدة، بس تفوت 0.38 |
| 0.3 | 9 |  **الأفضل** |
| 0.25 | 9 | نفس 0.3 (زيادة بلا فايدة) |

**القرار:** اعتمدنا **0.3** لأنه:
- يكشف كل المركبات الحقيقية
- بدون أخطاء
- لا يحتاج ننزل أكثر

## ملاحظات الأداء (YOLO11n الجاهز)

بعد اختبار 300 إطار (10 ثواني) من الفيديو، لاحظنا:

### ✅ نجح في:
- كشف السيارات بدقة عالية (ثقة 0.7+)
- كشف الباصات (ثقة 0.5+)
- كشف الشاحنات (ثقة متذبذبة)

### ⚠️ التحديات:

**1. الموتور:**
- يُكتشف كسيارة أغلب الوقت
- لحظة واحدة فقط عُرف كموتور
- السبب: الحجم الصغير والمسافة البعيدة

**2. الشاحنات الكبيرة:**
- قد تُكتشف كباص أو باصين
- أو كشاحنة + باص معاً (بسبب الطول)
- عند الاقتراب، تُعرف كشاحنة
