# 🚦 Midad Smart Traffic Project

نظام ذكي لعدّ وتصنيف المركبات على طريق مدفوع باستخدام **Computer Vision**.

## 📋 نظرة عامة

يهدف المشروع إلى تطوير نظام ذكي يُثبّت على كاميرا مراقبة فوق طريق مدفوع (Toll Road) ذي اتجاهين، بحيث يقوم النظام بـ:

- 🚗 **كشف المركبات** وتصنيفها (سيارة، باص، شاحنة، موتور)
- 🎯 **تتبع المركبات** بين الإطارات (SORT)
- 🔢 **عدّ المركبات** الفريد (بدون تكرار)
- 📊 **حساب الإحصائيات** لكل فئة

## 🛠️ التقنيات المستخدمة

- **Python 3.10+**
- **YOLO11n** (Ultralytics) — لكشف المركبات
- **OpenCV** — لمعالجة الفيديو
- **SORT** (Simple Online and Realtime Tracking) — لتتبع المركبات
- **filterpy + lap** — مكتبات SORT
- **NumPy** — عمليات رياضية

## ⚙️ الإعدادات المهمة

### عتبات الثقة (Confidence Thresholds):

```python
CONFIDENCE_THRESHOLD = 0.3

CLASS_THRESHOLDS = {
    2: 0.3,      # car
    3: 0.15,     # motorcycle ← أقل (لتحسين الكشف)
    5: 0.3,      # bus
    7: 0.3,      # truck
}
```

### خوارزمية SORT:
```python
tracker = Sort(
    max_age=20,          # عمر الـ track
    min_hits=1,          # الحد الأدنى للمطابقات
    iou_threshold=0.1,   # نسبة IoU الدنيا للربط
)
```
**ملاحظة:** iou_threshold = 0.1 —  جرّبنا قيم أخرى، وهذه الأنسب.

### خط العدّ:
```python
COUNTING_LINE_RATIO = 0.6   # 60% من ارتفاع الإطار
```

if det["class_name"] == "motorcycle":

## ⚠️ ملاحظات وتحديات

### 1. الموتور ضعيف الكشف

· YOLO11n يعاني في كشف الموتورات (خصوصاً البعيدة)
· **حل مؤقت**: عتبة أقل (0.15) + SORT
· **النتيجة**: 4 من 4 حقيقيين

### 2. الشاحنات الكبيرة

· YOLO يخلط بين bus و truck في الشاحنات الصهريجية
· **سبب**: تشابه من الخلف + حجم كبير
· **حل مؤقت**: لا يوجد حالياً

### 3. الموتور القريب جداً

· إذا كان الموتور قريب من الكاميرا، يظهر كبير → يُصنّف "سيارة"
· **سبب**: YOLO يخلط بناءً على الحجم
