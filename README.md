# 🚦 Midad Smart Traffic Project

نظام ذكي متكامل لكشف وتتبع وعدّ المركبات، بالإضافة إلى **حساب السرعة ورصد المخالفات وتحديد ألوان المرور والمخالفات بصرياً** مع **لوحة إحصائيات مباشرة** على طريق مدفوع باستخدام **Computer Vision**.

---

## 📋 نظرة عامة

يهدف المشروع إلى تطوير نظام ذكي يُثبّت على كاميرا مراقبة فوق طريق مدفوع (Toll Road) ذي اتجاهين، بحيث يقوم النظام بـ:

- 🚗 **كشف المركبات وتصنيفها:** باستخدام نموذج **YOLO مُدرّب مخصص (Roboflow Weights)** لكشف المركبات بدقة عالية (mAP@50: 84.6%).
- 🎯 **تتبع المركبات:** تتبع مستمر بين الإطارات باستخدام خوارزمية **SORT**.
- 🔢 **عدّ المركبات والاتجاهات:** عدّ فريد للمركبات عند عبور خط العدّ وتحديد الاتجاه (ذهاب/إياب).
- ⚡ **حساب السرعة:** حساب سرعة المركبات بالفريم بدقة (متر/ثانية ثم تحويلها لـ km/h).
- 🚨 **رصد المخالفات وتلوين الصناديق:** كشف تجاوز السرعة المحددة (مثلاً > 60 كم/س) وتلوين صندوق المركبة باللون **الأحمر** حصراً في حالة المخالفة، مع الحفاظ على الألوان الأصلية لكل فئة عند الالتزام.
- 📊 **لوحة إحصائيات مباشرة (Tkinter Live Dashboard):** عرض تفصيلي لعدد المركبات والرسوم والسرعة الحالية وحالة المعالجة في نافذة منفصلة.

---

## 🛠️ التقنيات والموديلات المستخدمة

- **Python 3.10+**
- **Custom Trained YOLO Model (`models/weights.pt`)** — تم تدريب النموذج وتصديره عبر Roboflow لتحسين كشف جميع الفئات.
- **OpenCV** — لمعالجة الفيديو والرسم البصري والتلوين الديناميكي.
- **SORT (Simple Online and Realtime Tracking)** — لتتبع المركبات وإعطاء ID فريد.
- **Tkinter / ttk** — لواجهة لوحة الإحصائيات المباشرة (Live Dashboard).
- **NumPy & Pathlib** — للحسابات المترية وإدارة المسارات.

## ⚙️ الميزات البرمجية الجديدة والوحدات (Modules)

### 1. وحدة حساب السرعة (`speed_calculator.py`)
تعتمد على حساب الإزاحة المكانية لمراكز صناديق المركبات بين الإطارات والتحويل من بكسل إلى أمتار بناءً على معدل FPS الخاص بالفيديو.

### 2. وحدة رصد المخالفات والتلوين الذكي (`violation_detector.py`)
- تقارن سرعة المركبة مع الحد المسموح (`speed_limit = 60.0 km/h`).
- ترجع اللون **الأحمر `(0, 0, 255)`** في حال تجاوز السرعة.
- تعيد **اللون الأصلي المحدد للفئة** (أخضر للسيارة، أزرق للموتور، إلخ) إذا كانت السرعة ضمن الحد المسموح.

### 3. لوحة الإحصائيات التفاعلية (`LiveStatsDashboard`)
- واجهة Tkinter تعمل بالتزامن مع الفيديو.
- تعرض جدول المركبات، الرسوم المحسوبة، اتجاه الحركة، وسرعة المعالجة (FPS).

## 📊 الإحصائيات ومعدلات الأداء

- **دقة النموذج المخصص (mAP@50):** 84.6%
- **ألوان الفئات عند الالتزام:**
  - 🚗 السيارة (`car`): أخضر `(0, 255, 0)`
  - 🏍️ الدراجة (`motorcycle`): أزرق `(255, 0, 0)`
  - 🚌 الباص (`bus`): أصفر `(0, 165, 255)`
  - 🚚 الشاحنة (`truck`): أرجواني `(255, 0, 255)`
  - 🚨 **أي مخالفة سرعة:** تجبر اللون على الأحمر `(0, 0, 255)`.
