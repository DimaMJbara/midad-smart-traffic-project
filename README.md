# 🚦 Midad Smart Traffic Project

نظام ذكي لعدّ وتصنيف المركبات على طريق مدفوع باستخدام **Computer Vision**.

## 📋 نظرة عامة

يهدف المشروع إلى تطوير نظام ذكي يُثبّت على كاميرا مراقبة فوق طريق مدفوع (Toll Road) ذي اتجاهين، بحيث يقوم النظام بـ:

- 🚗 **كشف المركبات** وتصنيفها (سيارة، فان، باص، شاحنة، موتور)
- 🎯 **تتبع المركبات** بين الإطارات (إعطاء ID فريد لكل مركبة)
- 🔢 **عدّ المركبات** الفريد (بدون تكرار)
- 📊 **حساب الإحصائيات** لكل فئة

## 🛠️ التقنيات المستخدمة

- **Python 3.10+**
- **YOLO11n** (Ultralytics) — لكشف المركبات
- **OpenCV** — لمعالجة الفيديو
- **خوارزمية تتبع بسيطة** (IoU + Centroid) — لتتبع المركبات

شو يعمل:

1. يحمّل موديل YOLO11n
2. يقرأ الفيديو من data/raw/traffic_video.mp4
3. يكشف المركبات في كل إطار
4. يعطي كل مركبة ID فريد (تتبع)
5. يعدّ المركبات اللي عبرت خط العدّ
6. يحفظ الفيديو الناتج في outputs/result_video.mp4
7. يطبع التقرير النهائي

⚙️ الإعدادات المهمة

عتبات الثقة (Confidence Thresholds):

```python
CONFIDENCE_THRESHOLD = 0.3

CLASS_THRESHOLDS = {
    2: 0.3,      # car
    3: 0.15,     # motorcycle ← أقل (لتحسين الكشف)
    5: 0.3,      # bus
    7: 0.3,      # truck
}
```

ملاحظة: عتبة الموتور أقل (0.15) لأن YOLO11n ضعيف في كشفه.

خط العدّ:
```python
COUNTING_LINE_RATIO = 0.6   # 60% من ارتفاع الإطار
```

معاملة خاصة للموتور في التتبع:

```python
if det["class_name"] == "motorcycle":
    max_dist = 300      # مسافة أكبر للتتبع
    max_age = 15        # عمر أطول في الذاكرة
```

⚠️ مشاكل معروفة

1. الموتور ضعيف الكشف

· المشكلة: YOLO11n يكشف الموتور بشكل متقطع
· الحل المؤقت: عتبة 0.15 + معاملة خاصة في التتبع
· النتيجة: كشف 6 من أصل ~5 حقيقيين
· الحل الجذري: Fine-tuning (خارج نطاق المشروع)

2. الشاحنات الكبيرة

· المشكلة: قد تُكتشف كباص أو كشاحنة + باص
· السبب: الطول + التشابه من الخلف
